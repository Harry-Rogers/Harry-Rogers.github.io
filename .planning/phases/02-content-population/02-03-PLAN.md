  <action>
    Detect image tooling in this order and use the first one found:

    1. ImageMagick 7 `magick`: `command -v magick`
    2. ImageMagick 6 `convert`: `command -v convert`
    3. `ffmpeg` (often present, can resize images): `command -v ffmpeg`

    Run resize to produce `assets/images/profile.jpg` at 800px on the long edge, JPEG quality 82:
    - `magick`: `magick assets/images/profile-original.jpg -resize 800x800^ -quality 82 -strip assets/images/profile.jpg`

    - `ffmpeg`: `ffmpeg -y -i assets/images/profile-original.jpg -vf "scale='if(gt(iw,ih),800,-1)':'if(gt(iw,ih),-1,800)'" -q:v 5 assets/images/profile.jpg`

    Verify output: `test -f assets/images/profile.jpg && [ "$(stat -c%s assets/images/profile.jpg)" -lt 400000 ]` (under 400 KB).

    FALLBACK (no tooling found): copy the original at full size as `assets/images/profile.jpg`, log a clearly-marked WARNING in the plan SUMMARY noting the file is oversized (6.3 MB), and add a follow-up TODO to STATE.md: "Resize headshot — install ImageMagick or use online tool, target < 400 KB at 800px long edge." Do NOT block the plan on tooling absence — the site must remain functional.

    Keep `assets/images/profile-original.jpg` in the repo (it is the source of truth per PROJECT.md decision "Resized derivatives generated in Phase 2; never serve the original").
  </action>
  <acceptance_criteria>
